# Connect Four

## About the Project

This project is a Python-based version of the classic Connect Four game. It was created as a group project where two players play against each other using the same device.

Players take turns choosing a column to drop their game piece into. The goal is to connect four pieces in a row horizontally, vertically, or diagonally before the other player.

## My Contribution

My main responsibility for this project was working on the actual game board display. I worked on how the board was created and displayed so players could clearly see the rows, columns, and game pieces. I also helped make sure the board updated correctly after each player's move.

## How the Game Works

The game starts by displaying the Connect Four board. Player 1 makes the first move, followed by Player 2. Players take turns choosing a column to place their piece in. After each move, the board is updated and the game checks to see if someone has connected four pieces.

The first player to connect four pieces wins. If the board fills up without a winner, the game ends in a draw.
